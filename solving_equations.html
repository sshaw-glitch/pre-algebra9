Solving Equations in 5 Steps

Each answer must be correct before the next box opens.

How to type your answers

Type equations like 5x+10=30. Spaces don't matter. Use - for minus. Write x (not 1x) when the number in front is 1.

Keep each step to just that step. Don't skip ahead.

Step 5 example: for 2(x + 1) + 3x = 17 with x = 3, type 2(3+1)+3(3)=17. A number right before x becomes a number right before parentheses. Put negative answers in parentheses, like 5(-4).
